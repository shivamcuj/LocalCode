# 702. Largest Element

Given an array of integers `nums`, return the value of the largest element in the array.

## Example 1

**Input:**
```text
nums = [3, 3, 6, 1]
```

**Output:**
```text
6
```

**Explanation:** The largest element in the array is 6.

## Example 2

**Input:**
```text
nums = [3, 3, 0, 99, -40]
```

**Output:**
```text
99
```

**Explanation:** The largest element in the array is 99.

## Function Signature

Implement the following method and return the largest integer in `nums`:

- **C++:** `int largestElement(vector<int>& nums)`
- **JavaScript:** `largestElement(nums)`
- **Python:** `largestElement(nums)`

## Input Assumption

The array contains at least one integer. No explicit numeric or array-length constraints were included in the supplied problem statement.
