# Pattern 4

Given an integer `n`, print a pattern containing `n` rows.

In row `i`, print the number `i` exactly `i` times, with no spaces between the numbers.

## Example 1

**Input**
```text
n = 4
```

**Output**
```text
1
22
333
4444
```

## Example 2

**Input**
```text
n = 2
```

**Output**
```text
1
22
```

## Constraints

- `1 <= n <= 100`

## Function

Implement `pattern4(n)` in the `Solution` class. The function must print the pattern; it does not need to return a value.
